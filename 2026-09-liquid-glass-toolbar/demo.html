Liquid glass toolbar

One glass surface that changes shape: a bar that opens into a search field, and then into a panel. Five materials, one construction.

At rest

Four actions cluster and the fifth is pushed to the end. The gap says the last item is a different kind of thing, before any label explains it.

The reveal

Every morph in the bar is one grid column going 0fr to 1fr under overflow: hidden. The track holds a label on four items and an input on the fifth, and does not know which.

  1. Indent, not padding. A box cannot be narrower than its own padding, so padded labels left an 11px stripe beside every collapsed icon. An indent disappears with the text and still counts toward the open width.
  2. The input is measured in a length. A text input has no meaningful max-content width, so that one track is a length rather than 1fr.
  3. Pinned from outside. --searching is a handle for callers that cannot synthesise the event. Click the bar and the pin drops — from there :focus-within runs it, with no script at all.

  1. The shape changes, not the stack. The panel row goes 0fr to 1fr, its width 0 to 30rem, and the shell re-measures around it.
  2. The corner never moves. --radius-open is pad + hit / 2, concentric with the corner actions; closed, 999px clamps to the same number. Height does all the work.
  3. Activity, not Notifications. Notifications is a promise about delivery. These four rows are a log — and the name keeps the component from being read as an alert centre.
  4. The extended view exposes a material. Four rows of small type over a sheet you can read the page through. Nothing in the panel is theme-aware.

Motion

Everything here animates layout — a track, a width, a radius, a surface measuring itself — so the smoothness had to come from the curve rather than from moving onto a transform.

--reveal · 220ms
The label track and the pill’s trailing pad. About 60px of travel.
--morph · 300ms
The panel row, the panel width and the corner. About ten times the distance, so it gets its own clock.
--fade · 140ms + 60ms in
The feed’s opacity. The delay is declared in the open state only, so closing snaps the text out instead of leaving it hanging in a collapsed box.

  1. No overshoot. A curve that passes 1 is lovely on a transform; on a width the bar grows past its size and comes back. With the surface centred, that is a wobble, not a bounce.

  1. A material is a whole palette. Tint, filter, rim, sheen, edge, drop, lozenge, ink, accent. The ink has to move with the tint, so it is not a hue rotation.
  2. Thin, not opaque. The tint came down to 28–44% and the work moved into the filter. Blur is frost: past about 10px the ground stops being a place. You should see the page’s cross-light continue across every sheet.
  3. Crystal is that argument at its end. At 7% it has almost no body, so it is carried by its edges — a rim, a white sheen, and a second hairline inside the bottom, standing in for the refraction CSS cannot do.
  4. Thinning costs contrast. White on moss went 2.3:1 to about 4:1 against the lit pill; crystal’s dark ink sits near 11:1. That is the number to watch if you re-tint this.

Narrow

Five 48px targets, four gaps and the surface’s own padding need about 264px. Below that it clipped its trailing action rather than getting tight.

  1. Scale, do not squeeze. One breakpoint moves only the values the file already derives from — the same component at 40px targets, not a second small one.
  2. A container query, not a media query. The box below is 15rem; the query reads that box, so the full-size bar further up is unaffected. Reading the viewport is wrong the moment this lands in a sidebar.
  3. The label is what goes. There is no room for it, so the reveal stays shut and the lit pill carries the selection alone.
